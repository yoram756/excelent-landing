גרסה: 0.3.0-isolated.20261028. חבילה זו מיועדת לפריסה מבודדת ללא שליחה. ספק: Cosend, לפי config/provider.json. אין לייבא שוב את טיוטות הייצור או לחבר מקור אירועי לקוחות.

מקור הגרסה הוא עבודת המעבר המקומית שנבדקה ב־84 בדיקות וב־15 בקרות שליליות. נוספה בדיקת פריסה scripts/deployed-e2e.mjs, המפעילה n8n סינתטי דרך השירות שנפרס, עם Credential סינתטי בלבד. תוצאות הפריסה עצמן מתועדות בנפרד ב־docs/runtime/WA_DEPLOYMENT_RESUME_20261028.md במאגר; בדיקות מקומיות אינן ראיית ייצור.

npm test מפעיל את בדיקות הספרייה. npm run build:workflows יוצר שלוש טיוטות כבויות עם נתיב placeholder. אין בכך הרשאה לייבוא או לפרסום מול לקוחות.

שרת HTTP מספק health, ingest ו־simulate-one בלבד. אין endpoint לשליחה. המודל ומתאם שליטת הספק הם ספריות תחומות ואינם מיובאים בשרת המבודד. ההעברה המקומית לנציג אינה הוכחה להקצאה בתיבת Cosend.

הפעלת scripts/deployed-e2e.mjs דורשת קונטיינר מסומן, volume סינתטי מזוהה, loopback משותף עם השירות ללא רשת חיצונית וסודות שירות סינתטיים. היא יוצרת DB ו־workflows נפרדים של n8n לצורך הבדיקה בלבד. אין להפעילה עם mounts או Credentials של ייצור.
