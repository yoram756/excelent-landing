## השינוי המוגבל שבוצע

עודכן רק העובד הידני הקיים, מאותו מזהה ובאותו פרויקט, מתוך מקורות הקוד החדשים read-one.mjs ו־read-one-workflow.mjs. צומת הסימולציה הישן נשמר מנותק ומושבת. הגיבוי המקורי נשמר בתיקייה מוגנת בשרת. כתובת ה־API קבועה ומאומתת, מזהים נבדקים לפני בניית הנתיב, הפניות HTTP חסומות, אין יצוא מפתחות, שמירת גוף, מודל או פעולות כתיבה.

לפני העדכון בוצעו git pull למקור המבודד ו־nginx -t בקונטיינר חד פעמי, exit 0. הייבוא בוצע ב־CLI הרשמי של n8n לעובד הקיים בלבד. לא נדרש restart לעובד ידני לא מפורסם. מקור פרוס: a6796d8bc8c641e0a7078bf4f844ce6e50425178. קבלה: server-postcheck.json.

הניסיון הראשון, 90041, נעצר בהגנה לפני קריאת גוף: רשימת השיחות מחזירה כברירת מחדל last_message=null. התיקון משתמש בנקודת GET /v1/messages המתועדת עם limit=1 ו־direction=inbound. נוספה בדיקת רגרסיה לשינוי הצורה. 90079 הוא ניסיון הקריאה היחיד שהחזיר גוף הודעה, uniqueMessagesRead=1. לא בוצעו ניסיונות שליחה או קריאה חוזרת של גוף לצורך אימות.

אין להציג את status=running שברשומות ההתחלה כהרצה פעילה או כהצלחה מלאה: שתי הרשומות מסומנות deletedAt בגלל מדיניות save none, stoppedAt=null ונתוני הריצה לא נשמרו. הוכחת הקריאה נשענת על פלט הצומת הסופי שהוצג בזמן אמת ונשמר כמטא נתונים בלבד, יחד עם הצלחת צמתי ה־GET בצילום. טיימר Logs שנותר בממשק אינו ראיית מצב שירות.
