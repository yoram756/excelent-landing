העמוד מציג את התוסף תחת Installed, עם שרת MCP אחד ומיומנות אחת. כלי בדיקת הרשאות האפליקציות מחזיר `not_installed` עבור מזהה התוסף, וכלי Cosend טרם הופיעו בסביבה זו. לכן אין להסיק מהעמוד שהתוסף מחובר, שהדוט קיבל גישה, או שקיימת הרשאת OAuth פעילה.

צילום העמוד והטקסט הנגיש נשמרו תחת `docs/evidence/20261028-dot-cosend/`. הטקסט נשמר ללא תוכן שיחות או סודות.

## החסם המדויק

הפעולה שנכשלה היא בקשת MCP לא מאומתת מסוג `tools/list` אל `POST https://mcp.cosend.app/mcp` מהמחשב המקומי. היא נכשלה לפני TLS או HTTP עם `ENOTFOUND`. התוצאה חזרה גם בהרצה שאושרה עם גישת רשת מורחבת. בדיקת DNS חיצונית מאמתת `NXDOMAIN`, בעוד שהדומיין הראשי של הספק נפתר.

אין HTTP Status או גוף תגובה מה־MCP, משום שלא נוצר חיבור. HTTP 200 בדוח DNS הוא תגובת שירות DNS בלבד ואינו הצלחת Cosend.

הפעולה הבאה היא לקבל מ־Cosend תיקון DNS או כתובת MCP חלופית פעילה ומתועדת. לא מנחשים כתובת חלופית, לא משנים ניתוב ולא מעתיקים מפתחות כדי לעקוף את התקלה. לאחר מכן יש להשלים OAuth בממשק המאובטח ולבדוק את סביבת אקסלנט והמספר `+972559881245`, מזהה `1138723472651617`, לפני קריאת הודעות.

טיוטת פנייה לספק, שלא נשלחה: “הכתובת המתועדת https://mcp.cosend.app/mcp מחזירה ENOTFOUND. בדיקת Google Public DNS החזירה NXDOMAIN / Status 3, בעוד cosend.app נפתר. נבקש לאשר כתובת MCP פעילה, Streamable HTTP ופרטי גילוי OAuth הנתמכים, או לתקן את רשומת ה־DNS. לא נדרש מאיתנו למסור מפתחות.”

## הרשאות ומצב נוכחי

חבילת OAuth מבקשת `messages:read`, `contacts:read`, `automations:read` ו־`templates:read` בלבד. שתי הראשונות מוגדרות כבסיס; אין בבקשה `messages:write` או הרשאות כתיבה אחרות. הרשאות מבוקשות אינן הרשאות שניתנו: OAuth עוד לא הושלם.

בקריאה בלבד בלוח Cosend אומתו שוב סביבת אקסלנט והמספר הרשמי. נצפו שלושה מפתחות לפי שם והיקף, ללא קריאת ערכים: מפתח n8n לקריאה עם `connections:read`, מפתח `n8n-Cosend-replies-0559881245` עם `messages:read`, `messages:write`, `connections:read`, ומפתח ותיק בעל היקף רחב. קיום מפתח אינו מוכיח שהוא זמין לדוט או שהוא מורשה לשימוש בו. לא נוצר, הועתק, סובב או בוטל מפתח.

הבהרת יורם: היעד כולל שליחה אוטומטית לאחר הגדרת ואישור כללים ובעלות יחידה. זו נשמרה במדיניות התוסף; שליחה כעת לא אושרה. [הצעת הכללים](ACTIVATION_RULES_DRAFT.md) מוכנה להמשך דיון, ולא מוצגת כאישור הפעלה.

אין מנוי נוסף, חיוב, שרת מתווך, קליטה מקבילה או הרחבת הרשאות של סוכן קיים. אין שימוש ב־ChatGPT כמקור להרשאת API נפרדת. התוסף נוצר לפי מיומנויות Plugin Management ו־Create Plugin; הקוד והחבילה נשמרו במאגר בנפרד משינויי LP1 והמשפך.
