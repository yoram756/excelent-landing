# אימות קריאה ב־TextMe ממחשב הענן של הדוט

PASS לבדיקת הקריאה בדפדפן הענן. חסם ההתחברות שתועד קודם נפתר לאחר שיורם התחבר והחזיר את השליטה לדוט. אין כאן אישור לחיבור API או לשליחת הודעות.

## מה אומת

| דרישה | מצב | ראיה |
| --- | --- | --- |
| השלמת כניסה בסביבת הדוט | PASS | חשבון `office@kho.org.il` מופיע בכותרת TextMe במחשב הענן, ללא מסך כניסה |
| פתיחת דוח השימוש בידי הדוט | PASS | הדוט דיווח על קריאת הדוח; לפי אישור יורם הועברה בקשת קריאה נוספת להשארתו פתוח, והוא נצפה בפועל במחשב הענן |
| כתובת הדוח | PASS | `https://my.textme.co.il/users-usage-report` נראתה בשורת הכתובת של הדפדפן בתוך מחשב הענן |
| טווח התאריכים | PASS | `01/10/26` עד `27/10/26`, בדיווח הדוט וגם בתצוגת הדוח שנבדקה ישירות |
| ראיית ספק | PASS | עמוד TextMe המאומת, כותרת ״דו״ח שימוש״, חשבון וטווח גלויים בתצוגת Live computer; אין הסתמכות על HTTP 200 בלבד |
| שליטה לאחר הבדיקה | PASS | השליטה הוחזרה לדוט; בתצוגה נצפה `Take over = 0` והדוט בעל השליטה. הדוח נשאר פתוח |
| הימנעות מפעולות שליחה ושינוי חשבון | PASS | בבדיקת TextMe לא הופעלו שליחה, תזמון, קמפיין, רכישה, ניהול טוקנים או עריכת הגדרות |
| חיבור API או הרשאת שליחה | NOT TESTED | לא נבדקו ולא הופעלו במסגרת בדיקת הקריאה |

הבדיקה מתייחסת למחשב הענן של ״העוזר של אקסלנט״, ולא ללשונית TextMe במחשב המקומי. בוצעה צפייה ישירה דרך תצוגת המחשב החי. ניתנה שליטה זמנית לצורך בדיקת התצוגה וסגירת חלונית תמיכה שהסתירה את החשבון והתאריכים; לא נשלחה פנייה לתמיכה. השליטה הוחזרה לדוט לאחר מכן ואומתה.

הדוח מציין שהוא מעודכן עד ליום העסקים הקודם. נתוני התקופה אינם הוכחה שלא הייתה פעילות היום. יתרה מפורטת ונתוני נמענים לא הועתקו לדוח זה.

לא נלכדו קוד HTTP או גוף API במהלך האימות החזותי, ולכן לא מיוחסים להם ערכים. ראיית ההצלחה היא מסך דוח אמיתי בסשן המזוהה של מחשב הענן, בצירוף תשובת הדוט והפרטים התואמים.

בבדיקה המשלימה לא נעשה שימוש בסשן Chrome אחר שהבעלות עליו לא אומתה. ניסיון בדיקת קלט מקלדת בתצוגת המחשב נדחה בסקירת אישור; לא בוצע ניסיון לעקוף את הדחייה. במקום זאת, לאחר אישור ממוקד נוסף של יורם, הדוט פתח שוב את אותו דוח בקריאה בלבד. חלונית התמיכה נסגרה בלחיצת סגירה בלבד, ללא הקלדה או משלוח.
